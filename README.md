# Kithul-official - E-Commerce Web Prototype

An e-commerce website designed and developed for showcasing heritage Kithul wood products.

##  Live Demo

[View Live Website](https://kithul-doorhandle-official.netlify.app/)


##  Features
- **Responsive UI/UX:** Mobile and desktop friendly interface.
- **Dynamic Cart System:** Real-time quantity adjustments and price calculations using JavaScript.
- **WhatsApp Integration:** Direct order formatting sent straight to WhatsApp.

##  Tech Stack
- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Netlify (Deployment)
